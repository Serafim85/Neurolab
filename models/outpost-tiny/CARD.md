public-LLM egress, JSON/extract and short code. Pilot pack and demo script:
[`docs/PILOT-CONTOUR-CHAT.md`](../../docs/PILOT-CONTOUR-CHAT.md).

## Limits

- **hammer2 filename alias.** `outpost-tiny-hammer2.Q4_K_M.gguf` is byte-identical to
  `outpost-tiny-hammer.Q4_K_M.gguf` (SHA256 `3a7129549bf19c69…`); one artifact, two names.
  Do not cite as two models. If you edit the generated block, `gen_model_card.py --check` must still pass.
- **Two eval numbers, never one.** The GGUF alone and the GGUF behind the
  Commercial runtime are different products. The runtime rows in the table
  above are canned short-circuits in Outpost, not model capability.
- **Scores are hand-graded, single run, N=10, temp 0.2.** There is no automatic
  scorer (`eval/README.md`). A ±1 delta between two rows is not evidence of an
  improvement. `ru_formal` for these weights is recorded as **2** in
  `eval/results/tiny-micro-vs-hammer2.md` and as **1** in the one verified
  hammer2 raw run of that day (`raw/baseline-20260721-163032`, one sentence,
  wrong sense) — two different recorded scores for the same GGUF.
- **Baseline columns are carried between reports.** The hammer2 column in
  `tiny-micro-vs-hammer2.md` has no raw run of its own on disk: the `Raw`
  field of that report points at `baseline-20260721-000725`, whose `meta.txt`
  names the **micro** GGUF.
- **Raw per-prompt evidence is not in git** (`.gitignore`: `eval/results/raw/`),
  and for the contour sheet the 20/20 run left an empty raw directory. The
  score tables in `eval/results/*.md` are currently the only record.
- **GGUFs listed below are 3B (`qwen-research`, research-only).** Locked base as of
  2026-08-13 is **Qwen2.5-7B-Instruct (Apache-2.0, NL-ADR-028)**. Do not ship a 3B
  artifact commercially. 7B scores are a new ladder — do not quote 17/20 or 20/20
  as 7B capability. See [`../../docs/BASE-LICENSE.md`](../../docs/BASE-LICENSE.md).
- Not a frontier chat model, not an agent runtime, not Mid/7–14B. Trained on
  lab-synthetic and curated data only — no customer personal data.
