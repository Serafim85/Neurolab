## 3. Последствие, из-за которого это важно

Производные наследуют ограничение. LoRA-адаптеры, merge и GGUF-экспорты, сделанные
от этой базы, — производные работы по §2.a. Это относится и к
`outpost-tiny-hammer.Q4_K_M.gguf`, то есть к **артефакту пилотного пака**.

Передача такого артефакта заказчику в составе коммерческого предложения — это
коммерческое использование, а не research/evaluation. По §2.b оно требует
отдельной лицензии Alibaba Cloud.

**Что этим НЕ затронуто:** Closed Sandbox (`sandbox/` не содержит весов),
методика eval, скорер, документация, брифы — там нет материалов Qwen.

## 4. Развилка, и она уже есть в дорожной карте

Размер 3B — **исключение** в линейке Qwen2.5. По состоянию на дату проверки
Apache-2.0 несут 0.5B / 1.5B / 7B / 14B / 32B; 3B — `qwen-research`; 72B — отдельная
лицензия Tongyi Qianwen со своими условиями (то есть не решение).

Значит переход locked base на **7B или 14B снимает ограничение целиком** — и это
ровно то, что уже описано в `docs/SCALE-PLAN.md` как Mid 7–14B. Смена базы
требует человека и ADR (`AGENTS.md` §9, первый пункт списка).

Проверять лицензию конкретного размера нужно **на момент решения**: условия
меняются, и вторичные источники врут. Пример: агрегатор `q4km.ai` утверждает про
этот же 3B, что «license permits commercial deployment» — это прямо противоречит
тексту §2.a/§2.b. Ориентир только один: файл `LICENSE` в официальном репозитории
модели.
