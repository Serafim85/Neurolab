## 3. Последствие, из-за которого это важно

Производные наследуют ограничение. LoRA-адаптеры, merge и GGUF-экспорты, сделанные
от этой базы, — производные работы по §2.a. Это относится и к
`outpost-tiny-hammer.Q4_K_M.gguf`, то есть к **артефакту пилотного пака**.

Передача такого артефакта заказчику в составе коммерческого предложения — это
коммерческое использование, а не research/evaluation. По §2.b оно требует
отдельной лицензии Alibaba Cloud.

**Что этим НЕ затронуто:** Closed Sandbox (`sandbox/` не содержит весов),
методика eval, скорер, документация, брифы — там нет материалов Qwen.

## 4. Развилка, и она уже есть в дорожной карте

Размер 3B — **исключение** в линейке. Проверено 2026-08-08 по метаданным карточек
моделей (не по пересказам):

| Размер (Instruct) | `license` | Вердикт |
|---|---|---|
| 0.5B | `apache-2.0` | коммерчески пригодна |
| 1.5B | `apache-2.0` | коммерчески пригодна |
| **3B** | `other` / **`qwen-research`** | **наша база — non-commercial** |
| 7B | `apache-2.0` | коммерчески пригодна ✅ |
| 14B | `apache-2.0` | коммерчески пригодна ✅ |
| 32B | `apache-2.0` | коммерчески пригодна |
| 72B | `other` / `qwen` | отдельная лицензия Tongyi со своими условиями — не решение |

Для 7B и 14B дополнительно проверен **сам файл** `LICENSE`, а не только поле
метаданных: первая содержательная строка — `Apache License`. Это не паранойя: у 3B
поле метаданных выглядело так же безобидно (`license: other`), пока не открыли текст.

Воспроизвести:

```bash
curl -sfL https://huggingface.co/Qwen/Qwen2.5-7B-Instruct/raw/main/README.md \
  | awk '/^---$/{n++; next} n==1' | grep '^license'
curl -sfL https://huggingface.co/Qwen/Qwen2.5-7B-Instruct/raw/main/LICENSE | head -1
```

**Вывод: переход locked base на 7B или 14B снимает ограничение целиком** — оба
Apache-2.0 и по метаданным, и по тексту. Это ровно то, что уже описано в
`docs/SCALE-PLAN.md` как Mid 7–14B. Смена базы требует человека и ADR
(`AGENTS.md` §9, первый пункт списка).

Проверять заново нужно **на момент решения**: условия меняются, а вторичные
источники врут. Пример: агрегатор `q4km.ai` утверждает про наш 3B, что «license
permits commercial deployment» — это прямо противоречит тексту §2.a/§2.b.
Ориентир только один: файл `LICENSE` в официальном репозитории модели.
